Critical Issues

HTML Corruption + Indexed Thin Content

Both issues were silently breaking the site and crawl budget — now fixed

BUG 01 — Unclosed Script Tag
In sections/main-product.liquid at line 72, the recently-viewed-products script was never closed with </script>. A second <script> opened immediately after, causing browsers to concatenate both scripts as one. This broke the DOMContentLoaded handler for the Framing Style variant selector on product pages.
// BEFORE (broken) } catch (e) { } <script> ← opened new script, never closed old document.addEventListener(...) // AFTER (fixed) } catch (e) { } </script> ← properly closes first script <script> document.addEventListener(...)
BUG 02 — Search Page Indexed
legxi.co/search?q=xyz was being crawled and indexed by Google. Search result pages are dynamically generated thin content with no unique value — indexing them wastes crawl budget and can cause duplicate content penalties. Fixed by adding request.page_type == 'search' to the noindex condition.
// BEFORE {%- if request.page_type == 'page' and noindex_handles contains page.handle -%} // AFTER (search also noindexed) {%- if request.page_type == 'page' and noindex_handles contains page.handle or request.page_type == 'search' -%} <meta name="robots" content="noindex, nofollow">
