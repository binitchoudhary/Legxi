Manual Steps — Action Required by You

5 Items
1

🔴 Unpublish "Demo" Product (Do Today)

Found in Shopify store: Product ID 9149038592174, Title "Demo", currently Active. Go to Shopify Admin → Products → "Demo" → Change status to Draft → Save. This removes it from Google's sitemap and stops it from wasting crawl budget.

2

🟠 Install a Review App (This Week)

Install Judge.me (free) or Yotpo from Shopify App Store. This enables AggregateRating schema which shows star ratings ⭐⭐⭐⭐⭐ directly in Google search results — can increase CTR by 20–35%.

3

🟠 Add Meta Descriptions to All Products (This Week)

Go to each product → scroll to the SEO section → add a 150–160 character description with keywords like "buy signed cricket ball india" or "Arshdeep Singh authentic memorabilia". The code now has a fallback, but a hand-written description always performs better.

4

🟠 Expand Blog Content to 800–1500 Words (This Month)

All 10 blog posts are currently ~400 words — Google considers this "thin content." Expand each post with stories, player stats, product details, and FAQs. Target commercial keywords: "buy signed cricket ball india", "cricket collectibles gift india", "arshdeep singh merchandise"

5

🟡 Set Up Google Business Profile (This Month)

Visit google.com/business and create a listing for LEGXI. This enables local search visibility and Google Maps presence. The LocalBusiness schema we added in code will connect to this listing once verified.
